# Custom Dropdown
This 'Custom Dropdown' project is a React and Typescript implementation of the roadmap.sh project challenge, and
has been created using a Vite template.

This dropdown shows a list of options when we click it. Once we select one of these, then the list is closed and the value of the option selected is shown in the dropdown placeholder. We can also change the current selection just clicking on any other option of the list. 

This components simulates a full functional dropdown component that receives by props different params, like the option list of items to be shown, the max-width that is allowed, the current selected value or the enabled/disabled state.

To start the project download it from the repository, then follow these steps:

1. Run `yarn install`
2. Run `yarn dev` to start the project locally
3. Open `http://localhost:5173/` in your browser to see the results

You can find all the information about this project in this site: https://roadmap.sh/projects/custom-dropdown.
